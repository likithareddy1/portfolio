# Kalluru Likitha — Portfolio

A responsive single-page portfolio made with HTML, CSS, and vanilla JavaScript. It has no build step or framework.

## Run locally

Open `index.html` directly in a modern browser. Google Fonts load online when available; system fonts are the fallback.

## Personalize

- The hero uses abstract CSS artwork and contains no profile photo. To personalize it, edit the initials and caption in `.visual-core` in `index.html`.
- Add verified dates, roles, responsibilities, and outcomes to the Infosys Springboard, AMD Agentic AI, and SmartBridge & APSCHE cards.
- Replace the project summaries/tags with accurate details. Project links currently point to the Contact section as editable placeholders; change them to real repository, prototype, or demo URLs when available.
- Edit the skills list. Add Figma, Git, GitHub, VS Code, or other tools only when they match your experience.
- Fill the education fields with your degree, institution, specialization, graduation year, and academic details.
- Replace `YOUR_EMAIL@example.com` in both `index.html` and `script.js`. Add your actual LinkedIn and GitHub URLs to the social links. The form validates locally and prepares a `mailto:` message; it does not send to a backend.

## Files

- `index.html` — semantic sections and content
- `style.css` — visual theme, responsive layouts, and reduced-motion support
- `script.js` — mobile menu, reveal behavior, current year, and contact form
